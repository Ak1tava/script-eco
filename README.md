# EcoWatch Karaganda

Локальный учебный MVP системы мониторинга качества воздуха в Караганде. Карта, история и предупреждения работают на **синтетических** данных — это не официальные измерения и не источник рекомендаций для здоровья.

## Что реализовано

- FastAPI + SQLAlchemy + PostgreSQL API;
- четыре демонстрационные станции в Караганде и шесть часов начальной истории;
- симулятор, который раз в 30 секунд в Docker-режиме отправляет новые пакеты (для реального режима поставьте `SIMULATOR_INTERVAL_SECONDS=300`);
- интерактивная карта OpenStreetMap, AQI-статусы, сводный dashboard;
- страница станции с последними загрязнителями и графиком за выбранный период;
- правила превышений, открытие/автозакрытие предупреждений и подтверждение оператором;
- базовый канал уведомлений: событие хранится в PostgreSQL и логируется в console-канал;
- идемпотентный API приёма датчиков: повтор одного пакета с тем же временем не создаёт дубликат.

## Быстрый старт

```bash
cp .env.example .env
docker compose up --build
```

Откройте:

- Dashboard: http://localhost:5173
- API и Swagger: http://localhost:8000/docs
- PostgreSQL: `localhost:5432` (значения из `.env`)

Остановка контейнеров: `docker compose down`. Данные PostgreSQL остаются в Docker volume. Чтобы начать с новой демонстрационной базой, выполните `docker compose down -v` — это удалит только volume этого проекта.

## Архитектура

```text
Симулятор / физический датчик
     │  POST /api/v1/ingest/measurements + X-API-Key
     ▼
FastAPI ──► PostgreSQL (станции, пакеты, alerts, notifications)
     │               │
     │               └── пороговый анализ + console notification adapter
     ▼
React / Vite dashboard ◄── REST API
```

Симулятор является лишь клиентом API: он не пишет в БД напрямую. Поэтому физическая станция заменяет только `backend/app/simulator.py`, сохраняя контракт запроса, ключ станции и расписание передачи.

## Контракт для физической станции

Каждая станция посылает `POST /api/v1/ingest/measurements` с заголовком `X-API-Key`. Минимальный пример:

```json
{
  "station_code": "KRG-001",
  "measured_at": "2026-09-08T08:00:00+00:00",
  "pm25": 34.2,
  "pm10": 59.8,
  "co": 1.2,
  "no2": 71.0,
  "so2": 22.5,
  "o3": 37.1,
  "temperature": -1.0,
  "humidity": 68.0,
  "source": "sensor"
}
```

Сейчас ключи демонстрационных станций намеренно лежат в `backend/app/seed.py`; для реального развёртывания их нужно перенести в provisioning-процесс или защищённое хранилище. API описан в Swagger (`/docs`).

## Правила MVP

AQI вычисляется по худшему из PM2.5 и PM10. Для предупреждений применяются настраиваемые пороги из `backend/app/services/air_quality.py`: PM2.5 — 55, PM10 — 150, NO₂ — 200, SO₂ — 350, O₃ — 180 µg/m³ и CO — 10 mg/m³. При возврате показателя ниже порога активное предупреждение автоматически закрывается.

## Проверка

```bash
cd backend
pytest
```

После старта откройте «Предупреждения»: начальные данные специально содержат тестовое превышение на станции «Майкудук», чтобы можно было проверить полный путь alert → notification → подтверждение.

## Сбор сводки IQAir для Караганды

`backend/scripts/iqair_karaganda.py` сначала находит все публично доступные станции на [странице IQAir для Караганды](https://www.iqair.com/air-quality/kazakhstan/karaganda/karaganda), затем получает сводку каждой станции. Скрипт дописывает по одной строке на каждую успешно обработанную станцию в `backend/data/iqair_karaganda_stations.csv`: время запуска по Караганде, название станции, время обновления у источника, US AQI, категория, основной загрязнитель и его концентрация. Список станций определяется заново при каждом запуске, поэтому новые станции будут подхватываться автоматически.

Запуск вручную из корня проекта:

```bash
python3 -m pip install -r backend/requirements.txt
python3 backend/scripts/iqair_karaganda.py
```

Чтобы запускать в 00:00, 05:00 и 14:00 каждый день по времени Караганды, откройте `crontab -e` и добавьте (замените путь к Python, если он другой):

```cron
CRON_TZ=Asia/Almaty
0 0,5,14 * * * cd /Users/aldos/Documents/ChatGPT/Ecology && /usr/bin/python3 backend/scripts/iqair_karaganda.py >> backend/data/iqair_collector.log 2>&1
```

Перед постоянным запуском проверьте правила использования и лимиты IQAir. Скрипт запрашивает городскую страницу и затем каждую найденную станцию с паузой в одну секунду; он не обходит ограничения. Ошибка одной станции не останавливает сбор остальных, а изменение формата или отсутствие всех станций будет зафиксировано в логе.
